# Application HotelRes

## Description
HotelRes est une application intuitive et performante qui permet à vos clients de réserver facilement leur séjour.  
L'objectif est simple : une solution mobile qui assure le suivi des réservations, tant pour l'hôtel que pour ses clients.

## Fonctionnalités
### Sélection et filtrage des chambres
- Sélection de chambres en temps réel
- Affichage des détails de la chambre choisie
- Filtrer des chambres en fonction des prix

### Réservation
- Réservation journalière ou par période
- Confirmation de réservation
- Synchronisation du calendrier

### Historique et confidentialité
- Conservation de l'historique de réservation
- Confidentialité des réservations

## Installation
1. Générer un token ici : <http://idefix.dti.crosemont.quebec:10170/auth/login>  
2. Insérer le token dans les préférences de l’application  
3. Compiler et lancer l’application depuis Android Studio
